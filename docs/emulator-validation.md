# Recorded emulator validation

These are historical checks on the recorded revisions, before the follow-up TLS/IME/CommsDat changes. New checks must identify their own revision. This file is not evidence that every pending game feature works.

## Legacy access points and retail Tomb Raider retest — 14 September 2026

The multilingual High Seize 1.0.2 archive was installed on two iOS simulators with its executable and DLLs unchanged. The reversible `highseize_setup` helper configured the native Arena XML endpoints and host mappings. Both clients selected **Host network**, completed Community and SNAP login, and reached room/commander setup. EKA2L1 exposes both legacy progress stages, EConnectionOpen (14) and EIfProgressLinkUp (1000). Its CommsDB patch creates the IAP and WAP associations through the ROM's database API; repeated opens and an existing configured database were byte-identical in the native probe.

The supplied multilingual Tomb Raider 1.0 archive contains a duplicate `tr` application registration whose executable is truncated to 512 bytes. That duplicate directory was backed up outside the guest. The real `tombraider.app` then launched successfully without executable changes. Its retail GSB launcher already exposes Arena; the existing sent-message cache repair was applied while preserving its import/protection data. Native login, directory browsing, download of a 642-byte Caves recording and playback passed. After removing the test installation's writable CommsDB file with a backup, the final WAP patch recreated it and Arena connected again using the rebuilt billing replacement, which no longer imports or edits CommsDB. A practice race completed, the native taunt form submitted, and the result page displayed **0.701 seconds, 0 points**, matching the persisted 701 ms result and noncompetitive challenge. This is a practice-result retest, not a new two-account challenge validation.

The Tomb Raider practice result used Release executable SHA-256 `7dfdb416b493c973980fda654dbc7a6b1df3b56758a7d5be922cbc2bb2f9c090`.
